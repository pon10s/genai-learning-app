# DESIGN.md — デザイン方針

> 見た目のブレを防ぐための約束。色・フォント・トーンを勝手に変えない。
> ※ 詳細はフェーズ5で詰める。ここは出発点。

## トーン

- 学習アプリらしい、**集中できる・落ち着いた**雰囲気。
- 情報量より「1問に集中」。余白を大切に。
- 正解／不正解のフィードバックは気持ちよく、でも派手すぎない。

## 配色（叩き台・後で確定）

- ベース：明るいニュートラル（白〜薄グレー）
- アクセント：知性を感じる青系（例 #2563eb）
- 正解：緑系（例 #16a34a） / 不正解：赤系（例 #dc2626）
- テキスト：濃いグレー（純黒は避ける、例 #1f2937）

## タイポグラフィ

- 日本語が読みやすいシステムフォント優先（游ゴシック / Hiragino / Noto Sans JP 系）。
- 本文は読みやすさ重視で行間ゆったり。

## レイアウト方針

- **モバイルファースト**（公開してスマホで使う前提）。
- カード型で1問ずつ提示。
- ボタンは押しやすい大きさ（スマホのタップ前提）。

## カテゴリの色分け（案）

- `trend`（最新トレンド）… 青
- `ai-dev`（AI駆動開発）… 紫
- `basics`（開発基礎）… 緑

> 確定はフェーズ5。それまでは最低限の見やすさを保つ程度でよい。
