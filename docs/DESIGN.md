# DESIGN.md — デザイン方針

> 見た目のブレを防ぐための約束。色・フォント・トーンを勝手に変えない。
> **採用テーマ：ポップ・楽しいゲーム風（Duolingo系）** — 2026-06-02 朱音さん決定。

## コンセプト

**「毎日つい開きたくなる、ごほうび感のある学習ゲーム」**

- 解くこと自体が楽しい。正解すると気持ちいい演出。
- 明るく前向き。むずかしそう・お勉強っぽさを出さない。
- スキマ時間にスマホでサクサク。1問が主役。

## 配色

- 背景：あたたかいクリーム（`--bg: #fff7ed` 系）。真っ白より親しみ。
- カード：白 `#ffffff`、角丸大きめ。
- テキスト：濃い茶グレー `#3f3a34`（純黒は避ける）。
- ブランド/アクセント：
  - パープル `#7c3aed`（メインCTA・ロゴ）
  - グリーン `#22c55e`（正解）
  - オレンジ `#f97316`（連続記録・強調）
  - レッド `#ef4444`（不正解）
- カテゴリ色：`trend`=パープル / `ai-dev`=オレンジ / `basics`=グリーン。

## かたち・質感

- **角丸を大きく**（カード 20–24px、ボタン 14–16px）。とにかく丸く。
- **立体ボタン**：下側に濃い影（3〜4px）を付け、押すと沈む（Duolingo風）。
- 影はやわらかく。線は細く控えめ、色で見せる。

## タイポグラフィ

- 日本語が読みやすいシステムフォント（Hiragino / Yu Gothic / Noto Sans JP）。
- 見出しは**太く大きく**、本文はゆったり行間。
- 数字（スコア・正答率）は大きく見せて達成感を出す。

## 動き（アニメーション）

- 正解：選択肢が**バウンド**＋チェック、軽い紙吹雪/きらきら。気持ちよさ重視。
- 不正解：横に**プルッと揺れる**（shake）。否定的にしすぎない。
- 画面遷移：ふわっとフェード／スライドイン。
- やりすぎ注意：1演出は短く（300–500ms）。学習の邪魔をしない。
- `prefers-reduced-motion` を尊重し、動きが苦手な人には控えめに。

## ゲーミフィケーション要素（段階的に）

- 進捗バー（今どこまで／全何問）を常に上部に。
- 連続正解コンボ、スコア、（将来）連続学習日数ストリーク🔥。
- 結果画面はごほうび感（大きな数字・ねぎらい・もう一度ボタン）。

## レイアウト

- **モバイルファースト**。片手で押せる大きいボタン。
- 1画面1問。情報を詰め込まない。

## 守ること

- 多色だが**使う色は決めた範囲内**で。無秩序に増やさない。
- 楽しさ優先でも**可読性・コントラスト**は確保。
- 依存ライブラリなしで実現（アニメはCSS中心、紙吹雪も自前の軽量実装）。
