# GLOSSARY.md — 用語集（先生の学習メモ）

> 開発や生成AIで出てきた言葉を、噛み砕いた説明で貯めていく場所。
> クイズ生成やコード作業で新出語が出たら、ここに1〜2行で追記する。
> 将来、アプリ内から参照できるようにする（フェーズ5）。

## 開発の基礎

- **Git（ギット）** … ファイルの変更履歴を記録・管理する道具。「いつ・何を変えたか」を残し、前に戻せる。
- **リポジトリ（repo）** … Gitで管理するプロジェクトの入れ物（フォルダ単位）。
- **commit（コミット）** … 変更を「ここまで」と区切って記録すること。セーブポイントのようなもの。
- **push（プッシュ）** … 手元の記録を GitHub（ネット上）へ送ること。
- **GitHub** … リポジトリをネット上に置いて共有・公開できるサービス。
- **GitHub Pages** … GitHub上の静的サイトをそのままWeb公開できる無料機能。

## 生成AI / LLM

- **LLM** … Large Language Model（大規模言語モデル）。大量の文章で学習した、文章を扱うAIの本体。
- **トークン** … LLMが文章を区切って処理する単位。料金や長さの上限の数え方にも使う。

## AI駆動開発

- **プロンプト** … AIへの指示文。良し悪しで出力が大きく変わる。
- **Claude Code** … ターミナル等で動くAI開発エージェント。コードの読み書き・実行を手伝う。
