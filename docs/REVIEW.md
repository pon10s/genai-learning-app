# REVIEW.md — セルフレビュー チェックリスト

> 各タスクの最後に、Claude（あなた）が自分で実施する。手戻りを減らすための関所。
> チェックして問題があればその場で直す。結果を一言 PHASES の進行ログに残す。

## A. 共通（毎タスク）

- [ ] 要件（REQUIREMENTS.md）から逸脱していないか。勝手に仕様を増やしていないか。
- [ ] CLAUDE.md の「やってはいけないこと」に触れていないか。
- [ ] 変更ファイルは最小限か。関係ない箇所を壊していないか。
- [ ] 命名・コメント・書き方が周囲のコードと揃っているか。
- [ ] CHANGELOG.md と PHASES.md を更新したか。

## B. コードを書いたとき

- [ ] 実際にブラウザ（または preview）で開いて、意図通り動いたか。
- [ ] コンソールにエラーが出ていないか。
- [ ] 想定外の入力（空・未回答・データなし）で壊れないか。
- [ ] 1ファイルが大きくなりすぎていないか。分割の必要は？
- [ ] localStorage のキー名が衝突・乱立していないか。

## C. クイズを生成したとき（WORKFLOW併用）

- [ ] 全問に出典URLがあるか。
- [ ] 事実が出典と矛盾していないか（読み直したか）。
- [ ] 解説が「学びになる」内容か。正解の根拠が書けているか。
- [ ] JSONがスキーマ通りで、アプリで正しく読めるか。
- [ ] `id` が重複していないか。

## D. デザインに触れたとき

- [ ] DESIGN.md の色・フォント・トーンから外れていないか。
- [ ] スマホ幅で崩れていないか（公開前提）。

## E. 学習サポートの観点（このアプリ特有）

- [ ] 先生（開発初心者）に対し、新しい用語・操作に一言解説を添えたか。
- [ ] Git等の操作をしたなら「何を・なぜ」を説明したか。
